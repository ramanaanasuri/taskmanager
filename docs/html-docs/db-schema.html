Task Manager Pro · Engineering reference

Database Schema

The eight MariaDB tables behind Task Manager Pro, as reported by DESCRIBE on the production database (Aug 2026). Tables are created and evolved by Hibernate (ddl-auto=update); the db/migrations SQL files mirror them for reference. Ownership is by email value on each row — there are no foreign-key constraints in the database, so the relationships below are enforced in the service layer.
